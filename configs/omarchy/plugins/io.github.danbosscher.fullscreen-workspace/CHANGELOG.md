# Changelog

## 1.0.0 — 2026-08-28

- Move windows entering true fullscreen to a configurable dedicated workspace.
- Optionally return each window to its original workspace when fullscreen ends.
- Configure focus following, startup routing, special-workspace handling, and
  excluded application classes through Omarchy Shell IPC.
- Exclude Omarchy's screensaver unconditionally.
- Cleanly unload and re-enable as an Omarchy headless service plugin.
